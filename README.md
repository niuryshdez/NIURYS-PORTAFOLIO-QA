## 🧭 Cómo navegar este repositorio

Si eres reclutador/a o tech lead, te recomiendo este recorrido de 5 minutos:

1. **[Proyecto 2 → Hallazgos destacados](2-SOLNARIS-ERP-QA-TESTING/README.md#-hallazgos-destacados)**: los bugs más relevantes y cómo los encontré.
2. **[Proyecto 1 → Excel de HU-01 Login](1-Y2K-QA-ANALISIS-FUNCIONAL/DOCUMENTOS/ANALISIS_FUNCIONAL_HU_01_LOGIN_Y2K.xlsx)**: abre la hoja *Resumen Ejecutivo* y luego *Criterios de Aceptación* (Gherkin).
3. **[Proyecto 1 → Hallazgos de seguridad](1-Y2K-QA-ANALISIS-FUNCIONAL/README.md#-hallazgos-de-seguridad-documentados)**: riesgos detectados desde el análisis, antes de ejecutar una sola prueba.

## 🛠️ Habilidades demostradas

**Análisis y diseño**
- Análisis funcional a partir de código fuente, manuales y entrevistas con desarrollo
- Reglas de negocio trazables a su fuente
- Criterios de aceptación en Gherkin (Given / When / Then)
- Partición de equivalencias y valores límite (BVA)

**Ejecución y reporte**
- Testing funcional, de regresión, exploratorio y por rol de usuario
- Validación de documentos electrónicos contra la autoridad tributaria
- Reporte de incidencias con severidad, pasos para reproducir y esperado vs. obtenido
- Re-test y cierre de cada incidencia junto al equipo de desarrollo

**Herramientas**
- Excel · Markdown · Git / GitHub · DevTools del navegador · Gherkin (BDD)
- Formación: Curso de Tester Funcional — Alianza Cultural (en curso)
